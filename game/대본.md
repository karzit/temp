```markdown
# NumPy 요약

import numpy as np 로 가져옵니다. arr 는 한 줄짜리 배열, m 은 표 모양 배열입니다.

## 만들기
np.array(리스트) — 리스트를 배열로 바꿉니다.
np.array([[1, 2], [3, 4]]) — 리스트 안에 리스트를 넣으면 표 모양이 됩니다.
np.arange(10) — 0부터 9까지 열 개. 끝 번호는 들어가지 않습니다.
np.zeros(5) — 0이 다섯 개.

## 계산 (값 하나하나에 적용됩니다)
arr * 2 — 모든 값에 2를 곱합니다.
arr + 10 — 모든 값에 10을 더합니다.
arr1 + arr2 — 같은 자리끼리 더합니다.

## 크기와 모양
len(arr) — 값이 몇 개인지.
arr.shape — 생김새. 한 줄이면 (5,), 표 모양이면 (줄, 칸).
arr.reshape(4, 3) — 4줄 3칸으로 모양을 바꿉니다. 개수가 딱 맞아야 합니다(4 × 3 = 12).

## 꺼내기 (번호는 0부터)
arr[0] — 0번째 값 하나.
arr[-1] — 맨 끝 값. 음수는 뒤에서부터 셉니다.
arr[1:3] — 1번부터 2번까지. 끝 번호는 포함하지 않습니다.
arr[-3:] — 뒤에서 세 개.
m[0] — 0번 줄 전체.
m[:, 1] — 1번 칸 전체(세로). 쉼표 앞이 줄, 뒤가 칸이고 : 는 전부라는 뜻입니다.
m[1, 2] — 1번 줄 2번 칸의 값 하나.

## 줄여서 하나로
arr.sum() — 합계
arr.mean() — 평균
arr.max() / arr.min() — 가장 큰 값 / 작은 값
arr.argmax() — 가장 큰 값이 몇 번째 자리인지
m.mean(axis=0) — 칸별 평균(세로). axis=1 이면 줄별 평균(가로).

## 조건으로 고르기
arr >= 80 — 값마다 참/거짓이 나옵니다. 고르는 것이 아닙니다.
arr[arr >= 80] — 그 참/거짓을 다시 대괄호에 넣으면 참인 값만 남습니다.
(arr >= 80).sum() — 참이 몇 개인지. 참은 1, 거짓은 0으로 세어집니다.
np.where(조건, 참일 때 값, 거짓일 때 값) — 자리마다 둘 중 하나를 골라 새 배열을 만듭니다.

## 줄 세우기
np.sort(arr) — 작은 것부터 늘어놓은 새 배열.
arr[::-1] — 순서를 뒤집습니다. 큰 것부터 보려면 sort 뒤에 붙입니다.
np.argsort(arr) — 값이 아니라 자리 번호를 순서대로 줍니다.
names[order] — 대괄호에 자리 번호 목록을 넣으면 그 순서대로 꺼내집니다.
```
